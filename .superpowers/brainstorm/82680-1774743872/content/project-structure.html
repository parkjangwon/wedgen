빌드 파이프라인 상세 (/api/generate)

POST /api/generate — ZIP 생성 프로세스
Request Body (multipart/form-data):
  ├── config: JSON string (폼 데이터 전체)
  ├── buildMode: "tweak" | "optimized"
  ├── templateId: "elegant-classic"
  └── images[]: File[] (원본 이미지 파일들)

Pipeline Steps:

  ┌─ 1. 입력 검증 ──────────────────────────────────────────────┐
  │  • templateId → /templates/{id} 존재 확인                    │
  │  • config → schema.json 기준 유효성 검증                     │
  │  • images → 파일 크기/형식 검증                              │
  └──────────────────────────────────────────────────────────────┘
                          │
                          ▼
  ┌─ 2. 이미지 처리 (sharp) ────────────────────────────────────┐
  │  • 모든 이미지 → WebP 변환                                   │
  │  • hero: max 1200x1600, quality 85                           │
  │  • gallery: max 800x800, quality 80                          │
  │  • thumbnail: 자동 생성 (lazy loading용)                     │
  │  • → Buffer[] 반환 (디스크 미저장)                           │
  └──────────────────────────────────────────────────────────────┘
                          │
                          ▼
  ┌─ 3. 설정 주입 (config-injector) ────────────────────────────┐
  │  • /templates/{id}/index.html 읽기                           │
  │  • <head> 내에 <script>window.__WEDGEN_CONFIG__=...         │
  │    주입 (JSON.stringify)                                     │
  │  • 에셋 경로를 상대 경로 (assets/xxx.webp)로 매핑            │
  └──────────────────────────────────────────────────────────────┘
                          │
                          ▼
  ┌─ 4. 빌드 모드 분기 ────────────────────────────────────────┐
  │                                                              │
  │  if buildMode === "tweak"                                  │
  │    └─ HTML, CSS, JS 원본 그대로 사용                         │
  │                                                              │
  │  if buildMode === "optimized"                              │
  │    ├─ HTML → html-minifier-terser                            │
  │    │   (collapseWhitespace, removeComments,                  │
  │    │    minifyCSS, minifyJS)                                 │
  │    ├─ JS  → terser                                           │
  │    │   (compress, mangle)                                    │
  │    └─ CSS → clean-css                                        │
  │        (level 2 optimization)                                │
  └──────────────────────────────────────────────────────────────┘
                          │
                          ▼
  ┌─ 5. ZIP 아카이빙 (archiver) ────────────────────────────────┐
  │  wedding-invitation.zip                                      │
  │  ├── index.html        (config 주입됨)                       │
  │  ├── style.css                                               │
  │  ├── script.js                                               │
  │  └── assets/                                                 │
  │      ├── hero.webp                                           │
  │      ├── gallery-1.webp                                      │
  │      └── ...                                                 │
  └──────────────────────────────────────────────────────────────┘
                          │
                          ▼
  Response:
    Content-Type: application/zip
    Content-Disposition: attachment; filename="wedding-invitation.zip"
    → 스트리밍 다운로드
